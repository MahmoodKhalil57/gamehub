# GameHub

Backend for GameHub, a tiny platform for party games: Supabase
(Postgres + Auth + Realtime + Row-Level Security). No app server.

- Database schema and security policies: `supabase/schema.sql` (already applied to the project).
- Frontend (plain HTML/JS/CSS, GitHub Pages): [MahmoodKhalil57/gamehub-ui](https://github.com/MahmoodKhalil57/gamehub-ui)
